# Trip The Loop — Into The Wild (Multi-Page Edition)

الموقع الرسمي لتجارب السفر والمغامرات في قلب الطبيعة المغربية — بنسخة متعددة الصفحات بروابط مستقلة لكل قسم.

## هيكل الملفات والروابط
- `index.html`: الصفحة الرئيسية (`https://anouarxhassouni-design.github.io/trip_the_loop/`)
- `destinations.html`: صفحة الوجهات (`.../trip_the_loop/destinations.html`)
- `trips.html`: صفحة الرحلات والفلترة (`.../trip_the_loop/trips.html`)
- `about.html`: صفحة قصتنا وفلسفتنا (`.../trip_the_loop/about.html`)
- `blog.html`: صفحة المدونة (`.../trip_the_loop/blog.html`)
- `shop.html`: صفحة المتجر (`.../trip_the_loop/shop.html`)
- `contact.html`: صفحة التواصل والحجز (`.../trip_the_loop/contact.html`)
- `css/styles.css` & `js/site.js`: ملفات التنسيق والبيانات والصور المشتركة بين جميع الصفحات.
- `.nojekyll`: لضمان عمل جميع الروابط على GitHub Pages بدون مشاكل.
