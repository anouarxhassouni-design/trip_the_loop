# Trip The Loop — Into The Wild (Flat Multi-Page Edition)

جميع ملفات الصفحات موجودة مباشرة في المجلد الرئيسي (بدون مجلدات فرعية) لضمان رفعها بسهولة على GitHub:

- `index.html`: الصفحة الرئيسية الكاملة
- `destinations.html`: صفحة الوجهات
- `trips.html`: صفحة الرحلات والفلترة
- `about.html`: صفحة قصتنا وفلسفتنا
- `blog.html`: صفحة المدونة
- `shop.html`: صفحة المتجر
- `contact.html`: صفحة التواصل والحجز عبر واتساب
