# Trip The Loop — Into The Wild

الموقع الرسمي لتجارب السفر والمغامرات في قلب الطبيعة المغربية.

## محتويات المشروع
- `index.html`: الموقع الكامل بجميع الواجهات والصفحات (الرئيسية، الوجهات، قصتنا، الرحلات والفلترة، المدونة، المتجر، والحجز عبر واتساب) مع دعم اللغات الثلاث (العربية، الفرنسية، الإنجليزية) وجميع الصور مدمجة بالكامل لضمان عدم ضياع أي رابط على GitHub Pages.
- `.nojekyll`: لضمان نشر الملفات مباشرة على GitHub Pages بدون معالجة Jekyll.

## طريقة الرفع على GitHub
1. فك الضغط عن الملف المضغوط.
2. ادخل إلى مستودع `trip_the_loop` على GitHub واضغط على **Add file > Upload files**.
3. اسحب ملف `index.html` وملف `.nojekyll` وأفلتهما في الصفحة، ثم اضغط **Commit changes**.
